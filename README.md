# 推し木 — あなたにぴったりの吉野杉と出会う（サンプル）

好きな木目や色の好みを診断して、相性のいい吉野杉を「推し木」としてスワイプで見つけるWebアプリのサンプルです。
推した木からは、同じ特徴の材 → 商品 → つくり手 → 体験 へとつながりをたどれます。

> 木・商品・つくり手の情報はすべて架空のサンプルデータです。

## 使い方

ビルドやインストールは不要です。`oshigi.html` をブラウザで開くだけで動きます（`file://` で直接開いてもOK）。

スマートフォンで見る想定のUIです（最大幅 440px）。PCではブラウザの開発者ツールでモバイル表示にすると確認しやすいです。

## 画面の流れ

1. **スタート** — 「木から」「使いみちから」「商品から」のどこから探すかを選ぶ
2. **好みチェック（診断）** — 年輪・節・色・木目・香り・使いみち・物語の7問。入口によって質問の順番が変わる
3. **MY TREE PROFILE** — 診断結果のタイプ名（例：朝日みたいな端正さん）と好みのメーター
4. **さがす（スワイプ）** — 相性の高い順にカードが並ぶ。右スワイプで推す、左でまた今度、タップで詳細
5. **マッチ演出** — 推すと桜の花びらが舞う演出
6. **詳細シート** — 相性がいい理由、木のおはなし。推した木なら「つながり」と「次にしたいこと」も表示
7. **推し木リスト** — 推した木の一覧

キーボード操作：カードにフォーカスして `←` / `→` で判定、`Enter` で詳細、`Esc` でシートや演出を閉じる。

### 実装メモ

- **フレームワークなし**：素の HTML / CSS / JavaScript だけで書いています。外部から読み込むのは Google Fonts だけです。
- **スクリプトの読み込み順**：`file://` でも動かすために ES Modules は使わず、通常の `<script>` でグローバル変数を共有しています。`oshigi.html` 末尾の `<script>` の順番を変えると動かなくなります。
- **保存**：回答・推した木・パスした木・気持ちは `localStorage` のキー `oshigi-sample-v1` に保存されます。リセットしたいときはこのキーを削除するか、スタート画面で入口を選び直してください。
- **ダークモード**：OS の設定に合わせて自動で切り替わります。`<html data-theme="light">`（または `dark`）で固定もできます。

## 木を追加・編集するには

`js/data.js` の `TREES` に要素を追加します。

| 項目 | 内容 |
| --- | --- |
| `id` | 一意な英字ID（イラストの乱数シードにも使われる） |
| `name` / `age` / `place` | 名前・樹齢・産地 |
| `rings` `knots` `color` `grain` `scent` `story` | 0〜1 の特徴値（年輪の細かさ、節の多さ、赤み、木目のゆらぎ、香り、物語性）。`story` を省略すると 0.5 になる |
| `uses` | `furniture` / `house` / `small` / `shop` の配列 |
| `price` | 価格帯 1〜5 |
| `tint` | カード背景色 |
| `feature` / `bio` | ひとこと特徴 / おはなし |
| `material` / `products` / `maker` / `exp` | つながり（材・商品・つくり手・体験） |

切り株のイラストは特徴値から自動で描かれるので、画像を用意する必要はありません。

### 相性スコアの計算

`js/logic.js` の `score()` で、各特徴について「好み」と「木の値」の近さを平均し（「どっちも好き」を選んだ項目は重みを 0.4 に下げる）、`40 + 類似度 × 50` に使いみちが合えば +9 を足します。上限は 99% です。
