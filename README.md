# 推し木 — あなたにぴったりの吉野の木と出会う（モック）

好きな木目や色の好みを診断して、相性のいい吉野杉・吉野桧を「推し木」としてスワイプで見つけるWebアプリのモックです。
推した木からは、同じ特徴の材 → 商品 → つくり手 → 体験 へとつながりをたどれ、材木カタログから見積もり・相談（モック）もできます。

> 木・商品・つくり手の情報はすべて架空のサンプルデータです。相談フォームも実際には送信されません。

## 使い方

ビルドやインストールは不要です。`index.html` をブラウザで開くだけで動きます（`file://` で直接開いてもOK）。

- **スマートフォン**：全画面で表示されます。
- **PC**（幅 640px 以上・高さ 720px 以上）：画面中央にスマホの枠つきで表示されます。発表やデモでそのまま見せられます。

## 画面の流れ

1. **スタート** — 「木から」「使いみちから」「商品から」のどこから探すかを選ぶ
2. **好みチェック（診断）** — 年輪・節・色・木目・香り・物語は、左右の絵を見比べて **5段階** で選ぶ（真ん中は「どっちでもいい」）。使いみちだけ4択。入口によって質問の順番が変わる
3. **MY TREE PROFILE** — 診断結果のタイプ名（例：朝日みたいな端正さん）、5段階のメーター、あなたに合う材木。結果のシェアもできる
4. **さがす（スワイプ）** — 相性の高い順にカードが並ぶ。右スワイプで推す、左でまた今度、タップで詳細。「もどす」で直前の判定を取り消せる
5. **マッチ演出** — 推すと桜の花びらが舞う
6. **木の詳細シート** — 相性がいい理由、木のおはなし。推した木なら「つながり」「次にしたいこと」「相談する」「推し木から外す」も表示
7. **推し木リスト** — 推した木の一覧（残した気持ちも表示）
8. **材木カタログ** — 12種類の材木を好みに近い順に表示。吉野杉／吉野桧で絞り込み。詳細から「見積もり・相談する」
9. **相談フォーム** — 入力チェックつきのモック。送信すると完了画面が出る（実際には送信しない）
10. **スタンプラリー** — 製材所・原木市場・工房・お店・森をめぐり、現地に掲示されたパスワードを入れるとスタンプが押せる。全6か所でコンプリート
11. **わたし（設定）** — 診断のやりなおし、送った相談の件数、データの全消去

キーボード操作：カードにフォーカスして `←` / `→` で判定、`Enter` で詳細、`Esc` でシートや演出を閉じる。

### 実装メモ

- **フレームワークなし**：素の HTML / CSS / JavaScript だけで書いています。外部から読み込むのは Google Fonts だけです。画像ファイルも使わず、イラストはすべて SVG をコードで描いています。
- **スクリプトの読み込み順**：`file://` でも動かすために ES Modules は使わず、通常の `<script>` でグローバル変数を共有しています。`index.html` 末尾の `<script>` の順番を変えると動かなくなります。
- **画面の描画**：各画面は `paint(html, 画面名)` で `<main>` に描きます。画面名が変わったときだけ入場アニメーションがつきます。
- **保存**：回答・推した木・パスした木・気持ち・相談の履歴は `localStorage` のキー `oshigi-sample-v1` に保存されます。「わたし」タブの「データをすべて消す」で初期化できます。
- **ダークモード**：OS の設定に合わせて自動で切り替わります。`<html data-theme="light">`（または `dark`）で固定もできます。

## スタンプラリー

`js/data.js` の `SPOTS` にスポットを並べています（架空）。各スポットのパスワードを入れると、そのスポットのはんこ風スタンプが台紙に押されます。
パスワードは、ひらがな・カタカナ・全角半角・大文字小文字・空白の違いを区別しません（例：「まるた」「マルタ」「 ﾏﾙﾀ 」はすべて正解）。

| スポット | 種類 | パスワード（デモ用） |
| --- | --- | --- |
| 川上村の製材所 | 製材所 | まるた |
| 吉野の原木市場 | 原木市場 | ねんりん |
| 東吉野村の家具工房 | 工房 | かんな |
| 下市町の箸工房 | 工房 | わりばし |
| 吉野の木のお店 | お店 | こもれび |
| 樹齢200年の森 | 森 | やまもり |

- スタンプは診断をやりなおしても消えません（「わたし」→「データをすべて消す」で消えます）。
- スポットを増やすときは `SPOTS` に1行足すだけで、台紙とスポット一覧に反映されます。`mark` はスタンプの中央に入る文字（1〜3文字）です。
- モックなので、パスワードはアプリの中に書かれています。本番では、サーバー側で照合するか、現地の QR コードに置き換える想定です。

## 診断（5段階）

年輪・節・色・木目・香り・物語の6問は、左（`opts[0]`）と右（`opts[1]`）の絵を比べて5段階で答えます。
位置 0〜4 が回答値に対応し、真ん中（位置 2）が「どっちでもいい」（0.5）です。

| 位置 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 意味 | とても左 | やや左 | どっちでもいい | やや右 | とても右 |
| 回答値（左=0, 右=1 の質問） | 0 | 0.25 | 0.5 | 0.75 | 1 |

## 木を追加・編集するには

`js/data.js` の `TREES` に要素を追加します。

| 項目 | 内容 |
| --- | --- |
| `id` | 一意な英字ID（イラストの乱数シードにも使われる） |
| `name` / `age` / `place` | 名前・樹齢・産地 |
| `species` | `sugi`（吉野杉）または `hinoki`（吉野桧）。省略すると `sugi` |
| `rings` `knots` `color` `grain` `scent` `story` | 0〜1 の特徴値（年輪の細かさ、節の多さ、赤み、木目のゆらぎ、香り、物語性）。`story` を省略すると 0.5 になる |
| `uses` | `furniture` / `house` / `small` / `shop` の配列 |
| `price` | 価格帯 1〜5 |
| `tint` | カード背景色（`#RRGGBB`。背景の山並みの色もここから作る） |
| `feature` / `bio` | ひとこと特徴 / おはなし |
| `material` / `products` / `maker` / `exp` | つながり（材・商品・つくり手・体験） |

スワイプのカードと木の詳細シートには、実物のイメージとして `pic/` の写真を表示します（写真の右下に「※イメージ」と表示）。どの木にどの写真を出すかは `js/data.js` の `TREE_PHOTOS` で決めています。素材が少ないので、特徴の近い木どうしで同じ写真を使っています。写真を割り当てていない木は、イラストで表示されます。

推し木リストやマッチ演出の切り株のイラストは特徴値から自動で描かれるので、画像を用意する必要はありません（年輪の数・節・色・木目のゆらぎ・樹皮の色が変わり、木ごとにキノコや桜の小物がつきます）。

## 材木カタログ

`js/data.js` の `SPECIES`（樹種）× `GRADES`（等級）から、12種類の材木 `MATERIALS` を自動で作っています。

| 等級 | 節 `knots` | 木目 `grain` | 目安 | おすすめの使いみち |
| --- | --- | --- | --- | --- |
| 生節一等 | 0.9 | — | 大小の節がたくさん | 構造材・床板・壁板 |
| 小節 | 0.6 | — | 直径25mmほどの節が1mに1個くらい | 床板・羽目板・棚板 |
| 上小節 | 0.35 | — | 直径10mmほどの節が1mに1個くらい | 内装の壁・天井・家具・カウンター |
| 特選上小節 | 0.15 | — | 鉛筆の芯ほどの節が2mに1個くらい | 和室の造作・見える柱・家具 |
| 無節 | 0 | — | 節がまったくない | 化粧柱・テーブル天板・建具 |
| 柾目 | — | 0 | 年輪がまっすぐ平行に並ぶ | 天井板・建具・まな板・小物 |

樹種は吉野杉（色 0.55）と吉野桧（色 0.15）です。等級が決めている項目（節、または木目）と樹種の色を好みと比べて、近い材木を選びます（`js/logic.js` の `materialFit()`）。

- **材木タブ**：12種類を好みに近い順に表示
- **プロフィール画面**：診断結果に近い材木を、杉・桧あわせて3つ表示
- **木の詳細シートの「同じ特徴の材」**：推した木と同じ樹種の中から、特徴が近い等級を2つ表示
- **材木の詳細シートの「この材に近い木」**：逆に、その材が近い木を表示

等級や樹種を増やすときは、`GRADES` か `SPECIES` に1行足すだけで、カタログに自動で反映されます。

### 相性スコアの計算

`js/logic.js` の `score()` で、各特徴について「好み」と「木の値」の近さを重みつきで平均し、`40 + 類似度 × 50` に使いみちが合えば +9 を足します。上限は 99% です。
重みは好みの強さで変わります（どっちでもいい = 0.4、やや = 0.7、とても = 1.0）。
